Native File Manager maintenance control

This installed service always boots idle. Recovery capability remains installed after repair and explicit Start.

The authorized native Dappnode manager controls this build through its normal File Manager. This private page cannot admit maintenance, repair, import, start or stop a ship. No custom bridge, controller certificate, or private Admin-origin interaction is required.

Repair and Start are separate native actions. A confirmed native container Stop and completed replacement are prerequisites to repair; a journal saying STOPPED is not cessation proof. Never clear or upload a replacement journal.

On uncertainty, retain the installed package, volume, command receipts and original evidence. Do not retry, restore the old image, or infer recovery from process absence. Restart does not reopen permission to repair or Start.
