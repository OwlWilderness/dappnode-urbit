# Draft licence preparation — not a release payload

This directory is additive local preparation. It is **not selected by the production notice manifest**, not installed in the accepted image, not a written offer, and not a declaration that publication is cleared.

Start with `../openssl-distribution-license-review.md` and its JSON companion. Proposed GPL/LGPL version choices are not owner-enacted changes to upstream or production notices.

## Contents

- `draft-recipient-notices.md`: reviewable recipient notice language, with deliberately unresolved release/source locators.
- `source-delivery-checklist.md`: concrete corresponding-source, relink, notice and delivery gates.
- `texts/`: exact licence/notice copies from the accepted source delivery, plus separately identified retained original attributions. Header-only examples are named as such and are not complete source files.
- `citation-ledger.json`: stable primary-source citation IDs and mechanically checked short quotes. Official GNU web retrieval timed out; exact full licence texts were read from retained primary release source. See the review's retrieval section.
- `evidence-receipts.json`: accepted archive member hashes, copied-text provenance, runtime-header and build-exception scope.
- `selected-source-notices.json`: bounded source-header scan, including conditional platform branches; not a binary SBOM.
- `source-cache-inventory.json`: declared upstream inputs versus retained package-cache trees; presence does not prove a complete source delivery.
- `verification.json`: file-only checks and explicit exclusions.

## Do not turn preparation into a licence change

Preserve MIT for the original covered Vere/urcrypt material, inherited attribution, and all applicable third-party grants. A GPLv3 combined-binary route does not mean replacing every repository/component licence with GPL. Do not edit accepted source or images merely to install these drafts. A future release worker must select the actual artifact, finalize notices and source delivery, and verify the resulting release binding under separate authority.

No private values are needed. Release/source locator fields below remain deliberately unfilled until an authorized retrievable publication exists.
